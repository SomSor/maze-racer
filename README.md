เกมเขาวงกตแบบสุ่มจาก เกม html js css ขนาด 10*10 ช่อง มีจุดเริ่มต้นและจุดจบเป็นช่องหนึ่งของวงกตของวงกต มีช่องกรอก textarea ชื่อคน บรรทัดละ 1 คน มีปุ่ม (random วงกตใหม่), (start game) วิธีเล่น ใส่ชื่อคนใน textarea แล้วกด (start game) แต่ละคนจะสุ่มได้สีประจำตัวและแสดงจุดที่ช่อง start แล้วแต่ละจุดจะเริ่มเคลื่อนไหวออกจากช่อง start ไปตามเขาวงกต ความเร็วขึ้นลงแบบสุ่ม ทิศทางแบบสุ่ม


Trail Spark แบบเบา
    ตอนผู้เล่นเคลื่อนที่ ให้ปล่อยจุดแสงเล็กๆ ตามสีผู้เล่น
    ช่วยให้การเคลื่อนไหวดูมีพลัง โดยไม่ต้องเปลี่ยน logic เกม
✅ Goal Burst ตอนเข้าเส้นชัย
    เมื่อผู้เล่น finish ให้ยิงวงแหวน/ดาวกระจาย 0.6-1.0 วินาที
    ต่อจากเอฟเฟกต์วงแหวนผู้ชนะที่มีอยู่แล้วใน renderer.js
✅ Thinking Bubble
    ตอน state เป็น thinking ให้มีบับเบิลจุดสามจุดลอยเหนือหัว (แทนข้อความจุดเฉยๆ)
    hook ได้จาก state ที่ตั้งใน ai.js
✅ Speed Pulse
    ความเร็วสูง = ออร่ากระพริบแรงขึ้น, ความเร็วต่ำ = อ่อนลง
    อิงค่าความเร็วที่สุ่มใน player.js
✅ Start Countdown Flash
    ก่อนเริ่มวิ่ง 3..2..1 ให้กระพริบช่อง start และสั่นเบาๆ ทั้งสนาม
    ผูกกับจังหวะเริ่มใน game.js
Fog of Excitement
    เปิดหมอกเล็กๆ รอบผู้เล่นแต่ละคน แล้วค่อยๆ จางระหว่างเกม
    เพิ่มความตื่นเต้นโดยยังคงเห็นโครงเขาวงกตหลัก
Dynamic Path Glow
    ถ้าเปิด shortest path ให้ glow วิ่งจาก start ไป goal แบบคลื่น
    เสริมของเดิมที่วาด path แล้วใน renderer.js
✅ Finish Podium Sequence
    เมื่อทุกคนเข้าเส้นชัย ให้เล่น animation จัดอันดับ 1-2-3 สั้นๆ
    ดึงข้อมูลจาก finishOrder ใน game.js
